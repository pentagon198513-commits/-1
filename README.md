# Тренажёр слепой печати на русском

Современный веб-тренажёр для обучения сотрудников компании слепой печати.
Цель — научить с нуля и довести до скорости **250–350 знаков в минуту**.

Стек: **Next.js 14 (App Router) + TypeScript + TailwindCSS**,
статический экспорт, разворачивается на **GitHub Pages** одной кнопкой.

## Идея и методика

Продукт собран из лучших практик СОЛО на клавиатуре, Ratatype, TypingClub,
Keybr и Monkeytype:

- **Методичность TypingClub**: 8 уровней от домашнего ряда до скорости
- **Адаптивность Keybr**: проблемные буквы попадают в дополнительные упражнения
- **Эстетика Monkeytype**: живые метрики, минимализм, тёмная тема
- **Геймификация СОЛО**: XP, уровни, ачивки, серии ежедневных занятий

## Возможности MVP

- 8 уровней, 16 уроков с пошаговой программой
- Экран тренировки с живыми метриками: скорость (WPM/зн.мин), точность, ошибки
- Виртуальная клавиатура ЙЦУКЕН с подсветкой:
  - жёлтый — следующая клавиша
  - зелёный — правильное нажатие
  - красный — ошибка
  - цвет рамки сверху — какой палец использовать
- Список уроков с целями по скорости и точности
- Страница статистики: график, лучшие результаты, проблемные буквы, XP, уровень
- Ачивки (9 штук) и система XP с нелинейными уровнями
- Лидерборд сотрудников (MVP — на локальных + демо-данных)
- Админ-панель: редактирование имени, экспорт данных
- Светлая и тёмная тема, плавные анимации
- Всё работает **без бэкенда** — данные в LocalStorage

## Деплой на GitHub Pages

1. Пушни репозиторий на GitHub.
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` при пуше в `main`:
   - собирает статику с `GH_PAGES_REPO=<repo_name>` (автоматически подставляет `basePath`);
   - публикует папку `out/` через `actions/deploy-pages`.
4. Сайт будет доступен по адресу `https://<org>.github.io/<repo>/`.

Если деплоишь не в `main`, измени триггер в `deploy.yml`.
Для кастомного домена добавь `public/CNAME` и уберёшь `basePath`/`assetPrefix`
из `next.config.js`.

## Горячие клавиши на экране тренировки

- Любая буква — печать
- `Backspace` — стереть последний символ
- `Esc` — сброс и попробовать заново

## Методика обучения

| Уровень | Содержание | Цель |
|---|---|---|
| 1 | Домашний ряд: ф ы в а — о л д ж | 10–15 WPM |
| 2 | Расширение: г ш п р | 18–20 WPM |
| 3 | Верхний ряд: й ц у к е н | 22–25 WPM |
| 4 | Нижний ряд: я ч с м и т ь | 25–28 WPM |
| 5 | Слова (частотные + рабочая лексика) | 35–40 WPM |
| 6 | Предложения, пунктуация | 45 WPM |
| 7 | Абзацы, рабочая переписка | 55 WPM |
| 8 | Скоростная печать | 70–80+ WPM (~300+ зн/мин) |

## План масштабирования

**v1.1 — Адаптивное обучение** *(фронтенд)*
- Генератор упражнений из проблемных букв
- Режим Keybr-подобной процедурной генерации «псевдослов»
- Подсказка правильной руки на схеме (визуал рук)

**v1.2 — Командный режим** *(бэкенд)*
- Подключить Firebase Auth + Firestore (миним. правки благодаря `lib/storage.ts`)
- Группы, роли, назначение уроков, отчёты
- Общий лидерборд, сравнение сотрудников, еженедельные челленджи

**v1.3 — Дополнительные режимы**
- Свободная печать (пользовательский текст)
- Тест скорости 60 сек
- Соревнование в реальном времени (WebSocket / Firebase RTDB)
- Диктовка (Web Speech API)

**v1.4 — Качество**
- E2E-тесты (Playwright) на сценарии уроков
- Юнит-тесты движка печати и метрик (Vitest)
- Accessibility pass (ARIA, фокус, screen reader)
- Метрики обучения: heatmap клавиш, «анализ аккорда» (пары клавиш, где теряется скорость)

## Архитектурные решения

- **Статический экспорт**: весь контент — статический, данные живут в LocalStorage. Это позволяет хостить на GitHub Pages без бэкенда.
- **Абстракция `lib/storage.ts`**: UI нигде не трогает LocalStorage напрямую. При переходе на Firebase меняется только реализация модуля.
- **Features-модули**: доменная логика отделена от UI. `useTyping` — чистый хук, его можно переиспользовать в любом интерфейсе (например, в мобильной версии).
- **Данные уроков — TypeScript**: строгая типизация, легко расширять. Позже можно вынести в JSON/CMS.
